# Telegram Claude Bot

Telegram-бот на TypeScript (Telegraf), который отвечает пользователю с помощью Claude API. Хранит короткую историю диалога в памяти процесса (последние 20 сообщений на чат).

Локально бот работает через long polling. На Render (бесплатный тариф) — автоматически переключается на webhook, чтобы не требовался платный Background Worker.

## Возможности

- `/start` — приветствие, сброс истории
- `/reset` — очистить историю диалога текущего чата
- `/help` — краткая справка
- Обычные текстовые сообщения обрабатываются через Claude API с учётом истории переписки

## Установка (локально)

1. Установите зависимости:

```bash
npm install
```

2. Скопируйте `.env.example` в `.env` и заполните значения:

```bash
cp .env.example .env
```

- `TELEGRAM_BOT_TOKEN` — получите у [@BotFather](https://t.me/BotFather) в Telegram (команда `/newbot`)
- `ANTHROPIC_API_KEY` — создайте в [Anthropic Console](https://console.anthropic.com/)

## Запуск в режиме разработки

```bash
npm run dev
```

## Сборка и запуск в production (вручную)

```bash
npm run build
npm start
```

## Деплой на Render.com (бесплатно)

Бот использует long polling, а Render на бесплатном тарифе не поддерживает Background Worker (только платно, от ~$7/мес). Поэтому для бесплатного деплоя код настроен так, что при наличии переменных окружения `PORT`/`RENDER_EXTERNAL_URL` (Render подставляет их сам) бот автоматически переключается в режим **webhook** и поднимает обычный HTTP-сервер — это уже помещается в бесплатный Web Service.

Важный нюанс бесплатного тарифа: сервис "засыпает" после ~15 минут без входящих HTTP-запросов. Так как Telegram сам стучится к боту по webhook, бот "просыпается" при получении сообщения — просто первый ответ после простоя может прийти с задержкой в несколько секунд, пока Render поднимает контейнер.

### Шаги

1. **Залейте код в GitHub-репозиторий** (публичный или приватный — Render поддерживает оба варианта).

2. **Зайдите на [render.com](https://render.com/)** и создайте аккаунт (можно через GitHub).

3. **New + → Web Service**, подключите ваш репозиторий.

4. Заполните настройки сервиса:
   - **Runtime**: Node
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`
   - **Instance Type**: Free

5. В разделе **Environment** добавьте переменные:
   - `TELEGRAM_BOT_TOKEN` — токен бота
   - `ANTHROPIC_API_KEY` — ключ Anthropic API

   Переменные `PORT` и `RENDER_EXTERNAL_URL` задавать не нужно — Render создаёт их автоматически для Web Service.

6. Нажмите **Create Web Service**. Render соберёт и задеплоит проект. После первого успешного деплоя бот сам зарегистрирует webhook в Telegram при старте процесса (используя `RENDER_EXTERNAL_URL`).

7. Проверьте бота в Telegram — напишите ему `/start`.

> Также в репозитории есть `render.yaml` — можно создать сервис через [Render Blueprints](https://render.com/docs/blueprint-spec) одной кнопкой, вставив URL репозитория на странице **New + → Blueprint**.

### Если нужен более надёжный вариант (без "засыпания")

Для полностью постоянного аптайма и без задержек на "пробуждение" можно перейти на платный **Starter** инстанс Web Service (от $7/мес, не "спит") или на **Background Worker** с long polling (тоже от $7/мес) — тогда переменные `PORT`/`RENDER_EXTERNAL_URL` можно не использовать, код и так упадёт обратно на long polling, если их нет.

## Структура проекта

```
src/
  index.ts       — вся логика бота
```
